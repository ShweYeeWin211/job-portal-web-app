# job-portal-web-app


A comprehensive full-stack Job Portal Web Application designed to connect job seekers with employers across various cities in Myanmar. The platform allows users to browse job vacancies by location, position, and salary, while providing an administrative dashboard to manage job postings and applications efficiently.

---

## ✨ Key Features

### 👤 Job Seeker (User Module)
* User Registration & Authentication: Secure sign-up and login system for job seekers.
* Job Search & Filtering: Browse and search job listings across different cities with detailed information on job titles, salary ranges, and company requirements.
* Online Application: Apply directly to preferred job positions and track application statuses.

### 🛠️ Administrator (Admin Module)
* Job Management: Post new job vacancies, update existing listings (salary, location, job descriptions), and remove closed positions.
* Application Review: View incoming candidate applications and manage recruitment decisions (approve/reject).
* Dashboard Overview: Centralized control panel to monitor active jobs and registered users.

---

## 💻 Tech Stack
* Frontend: HTML5, CSS3, JavaScript
* Backend: PHP
* Database: MySQL
